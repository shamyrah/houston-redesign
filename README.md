# City of Houston Public Works — Accessibility Redesign

A front-end redesign of the [City of Houston Public Works utility billing website](https://www.houstonwaterbills.houstontx.gov/ProdDP/Default/Default) focused on WCAG 2.1 AA compliance, semantic HTML structure, and inclusive design for all users.

---

## Project Overview

This is a portfolio case study and work-in-progress redesign targeting the accessibility gaps in Houston's existing utility billing site. The goal is to produce a clean, compliant, and user-friendly interface that meets the accessibility standards required of government websites under Section 508 and WCAG 2.1 AA.

---

## Goals

- Achieve WCAG 2.1 AA compliance across all core pages
- Rebuild with semantic, accessible HTML from the ground up
- Establish a consistent, brand-aligned design system using CSS custom properties
- Demonstrate accessible component states (normal, focus, error) across interactive elements
- Serve as a primary front-end portfolio case study targeting digital accessibility roles

## Accessibility Approach

- **Color system** — HSL-based CSS custom properties built from Houston's official brand palette, tested for contrast ratios meeting WCAG AA (4.5:1 text, 3:1 UI components)
- **WAVE audits** — Regular automated scans to catch missing alt text, heading hierarchy issues, and contrast failures
- **Keyboard navigation** — Manual testing for focus order, focus visibility, skip links, and no keyboard traps
- **Semantic HTML** — Correct use of landmarks, headings, lists, and ARIA where native HTML falls short
- **Component states** — Designed normal, focused, and error states for all interactive elements in Figma before building
